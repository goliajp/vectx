signed distance fields.

Each shape is a function f(x, y) → distance to surface. Negative inside, positive outside. Boolean ops are pure arithmetic — union = min(a, b), intersect = max(a, b), subtract = max(a, −b). Smooth blending is one extra line and one extra parameter k. This is what vectx could expose as a second primitive family alongside Frame / Circle / Path. See ./README.md for the writeup.

SDF primitives sdCircle(p, r) = length(p) − r sdBox(p, b) = length(max(|p|−b, 0)) + min(max((|p|−b).x, (|p|−b).y), 0) Composition union a, b → min(a, b) intersect a, b → max(a, b) subtract a, b → max(a, −b) smoothUnion a, b, k → mix(b, a, h) − k·h·(1−h) where h = clamp(0.5 + 0.5·(b−a)/k, 0, 1)
